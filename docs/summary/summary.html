aroma-rs: structural code search for Java, Apex and Salesforce

Summary

Structural code search retrieves code whose parse-tree structure resembles a partial snippet, but enterprise platforms mix general-purpose languages, markup, and declarative metadata. aroma-rs is a Rust and tree-sitter re-implementation of the retrieval pipeline of Aroma (Luan et al., OOPSLA 2019) that indexes a single repository and returns structurally similar code with the matching region highlighted. Eight language adapters (Java, Apex, Lightning Web Components JavaScript and HTML, Salesforce XML metadata, Aura markup and JavaScript, and Visualforce) feed one language-agnostic core. In reference-compatibility mode, the implementation matched the authors' reference implementation on 520/520 golden cases at every pipeline stage. The project evaluated self-retrieval recall on five-line query slices with a default and a held-out sampling seed, and hand-written idiom suites that hold out the source and its exact clones. On a 15-task metadata suite, structural retrieval placed the target idiom in the top five for 7/15 tasks (46.7%) versus 3/15 (20.0%) for a BM25-only baseline. Predefined recall@100 gates passed for every language (0.9823–1.0000), but LWC JavaScript recall@1 was 0.9489 and 0.9477 on the two seeds, below its 0.95 gate. Aroma's clustered recommendations remain experimental: at the Aroma paper's thresholds, clusters formed for only 7–19% of queries on three Apex repositories. One-shot command-line queries took a median of 90.4 ms on 233,318 Java units. Self-retrieval measures findability, not usefulness, and the idiom suites are small and developer-written. These results suggest that one structural core can serve heterogeneous Salesforce artifacts; shortfalls are reported rather than tuned away.

Limitations

  • Self-retrieval recall measures whether an existing unit can be found again, not whether results help a developer.
  • The idiom suites are small (40, 20 and 15 tasks) and were written by the developers; there was no user study.
  • Single repository per index; all measurements on one machine; CI had not run when these results were recorded.
  • The Java recall@1 gate passed with no headroom, using a display rule chosen on the release corpus.
  • Aroma's clustered recommendations recorded 0 wins, 4 ties and 1 loss against the top-5 similar results, so they stay experimental.
