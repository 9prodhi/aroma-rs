## Harness finding during this run

`java_corpus(n)` deletes every Java repository beyond the first `n` from the shared corpus
directory. Earlier `recall` runs (default 20) and a 2-repository perf smoke had shrunk the
fixture, so the first perf runs this afternoon reported 124,618 / 104,793 units. Tracked in
TODOS.md ("Non-destructive Java fixture selection").
